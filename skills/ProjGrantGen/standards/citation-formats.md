# 参考文献著录格式（Vancouver 顺序 + 中文国标）

本文件为 ProjGrantGen 自带，定义立项依据参考文献的著录与引用完整性规则。脚本
`scripts/renumber_citations.py` 依据本规则自动生成列表：标题含中文用中文格式，
否则用 Vancouver 英文格式。

## 1. 引用完整性红线

- 正文每一条 `[N]` 引用，必须在参考文献列表中有对应条目。
- 参考文献列表每一条，必须在正文被引用至少 1 次（孤儿条目/孤儿引用均禁止）。
- 图注、表注、附录沿用正文同一顺序编码。
- 不得出现占位区间如 `[21-157]`；每个编号对应一篇真实、单独被引的文献。
- 摘要、关键词、标题**零引用**。
- `validate_proposal.py` 会在渲染前校验"正文引用集合 == 列表集合"。

## 2. 正文内引用写法

- 单篇：`[1]`、`[2]`（方括号）。
- 多篇不连续：`[1,3,5]`（逗号分隔，**不要**写成 `[1],[3],[5]`）。
- 连续 3 篇及以上：`[1-5]`。
- 混合：`[1,3-5]`（表示 1、3、4、5；2 已在别处引用，不并入）。
- 位置：置于论断之后、句号之前 —— "<核心机制>与<疾病/现象>密切相关 [[3],[5],[12]]。"（**占位示意，实际用本项目论断**）
  起草阶段用临时标记 `[[ref_no]]`，**定稿后**由 `renumber_citations.py` 重编号为最终 `[N]`。
- 禁止夸大区间：如 `[49-200]` 必须保证区间内每个数字都对应一篇真实被引文献。

### 2.1 引用精确性红线（并列的**具体对象**必须逐项对应标注）

**规则**：句中并列列举**多个具体对象**（方法 / 工具 / 模型 / 数据库 / 数据集 / 算法 / 基因 / 蛋白 / 药物 / 队列）时，
**每个对象后面紧跟它自己的文献编号**，让"对象↔文献"一一对应、可逐条溯源；
**禁止**把若干对象并列后用一组编号笼统覆盖。

| 写法 | 示例（对象名与编号均为**占位示意**，实际以 `selected_papers.json` 为准） | 判定 |
|------|------|------|
| ✅ 逐项对应标注 | `……（如 方法A[11]、模型B[12]、工具C[13] 等）已展现优于传统方法的表现` | 正确：每个对象对应自己的文献 |
| ❌ 一组编号笼统覆盖 | `……（如 模型A、模型B、工具C 等）已展现优于传统方法的表现[11,13,17]` | **错误**：编号与对象对不上，无法溯源，且 3 个对象只引 3 篇中的 1 组编号笼统覆盖 |

**判定要点**：
1. **一个编号对应一个具体对象**；对象数 > 编号数 即为缺陷（应逐项补齐，或删掉无对应文献的对象）。
2. **示例中的对象名（模型A/工具B 等）与编号仅为占位示意**：写作时用当前项目的真实对象（方法/工具/模型/基因…）与其在 `selected_papers.json` 中的真实 `ref_no`；示例本身不代表任何特定领域或项目，**不得照抄占位名**。
3. 若某对象确实**没有独立文献**（例如仅在综述中被提及），要么不列该对象，
   要么在该对象后标注其出处（综述/基准测试）编号并说明，不得混在一组编号里。
4. **结论性/综述性论断**（不针对具体对象）可用分组编号，如"该方向仍缺乏统一评测[10,11,19]"——此情形不受本红线约束。
5. 起草阶段同样要求逐项标注：`对象A[[ref_no]]、对象B[[ref_no]]…`，
   重编号后自动变为 `对象A[N]、对象B[N+1]…`（`ref_no` 取自 `selected_papers.json`）。

**自检**：通读每个含引用的句子，逐条问"这个编号指向的文献，是不是正好就是这个对象/这个论断？"——
答不上来即说明引用与内容对不上，必须修正。

## 3. 参考文献列表格式

> 列表由脚本自动生成，每条**独立成段**（便于 docx 悬挂缩进）。以下为人工核对的依据。

### 3.1 中文期刊论文（默认用于中文标书）

```
[N] 作者. 文题[J]. 期刊名, 年份, 卷(期): 起止页码.
```
例：`[1] 陈小明, 王丽华, 李志强, 等. 深度学习在药物发现中的应用进展[J]. 药学学报, 2024, 59(3): 456-472.`

- 作者超过 3 人：列前 3 人后加"等"（中文习惯）。
- 卷(期)缺失时退化为 `年份: 起止页码.` 或仅 `年份.`。

### 3.2 英文期刊论文（Vancouver）

```
[N] Author AB, Author CD, Author EF, et al. Title. J Abbrev. Year;Vol(Issue):Pages. doi:DOI.
```
例：`[1] Chen X, Wang Y, Li Z, et al. Deep learning for drug discovery: a systematic review. Nat Rev Drug Discov. 2024;23(5):345-367. doi:10.1038/s41573-024-00912-x.`

- ≤6 位作者全列；≥7 位列前 6 位加 `et al.`
- 有 DOI 必带。

### 3.3 图书 / 学位论文 / 专利（中文）

- 图书：`[N] 作者. 书名[M]. 版次. 出版社, 出版年.`
- 学位论文：`[N] 作者. 论文题目[D]. 授予单位所在地: 授予单位, 授予年份.`
- 专利：`[N] 发明人, 发明人, 申请人. 专利名. 专利国别 专利号. 年份.`

### 3.4 其他类型（英文）

- 会议：`[N] Author AB, Author CD. Title. In: Proc of Conf Name; Year; Location. Publisher; Year. p. Pages. doi:DOI.`
- 网站：`[N] Organization. Page title. URL. Published Date. Accessed Date.`
- 数据集：`[N] Creator. Title of dataset. Repository; Year. doi:DOI.`

## 4. 常见坑

- **缺 DOI**：有则必带。
- **作者格式不一致**：全列表一格式，名缩写带点。
- **卷期页缺失**：留空也优于臆造。
- **重复条目**：同一篇不得占两个号。
- **DOI 未核验**：引用前确认 DOI 解析到正确文献。
- **预印本一律禁止引用**：任何领域（含 CS/AI）的 arXiv、bioRxiv、medRxiv、Research Square、SSRN 等预印本均不得进入参考文献列表；只引**经同行评议的正式出版版本**（期刊论文/会议正式论文集/专著）。只有预印本而无正式版的论文不选。
