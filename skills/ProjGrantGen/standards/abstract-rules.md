# 标准 7：项目摘要（≤400 字，最后写）

## 1. 位置与时机

- **位置**：按模板放在"项目摘要"（位于"一、项目基本信息"之后、"二、主要参与者"之前）。
- **时机**：**最后撰写**。必须等立项依据、研究内容、目标、关键问题、创新点、研究基础全部定稿后再凝练，确保摘要与全文一致。

## 2. 字数硬约束（最关键）

- **不超过 400 字**。计数规则（与用户约定一致）：
  - **每个汉字 = 1 字**；
  - **每个标点符号 = 1 字**（，。、；：""''（）【】等全算）；
  - **每个英文字母/数字 = 1 字**（a、b、1、2 各算 1 字；单词 apple 算 5 字）；
  - **空格不计入**（仅作为分隔，不参与字数）。
- 用 `scripts/count_abstract.py` 自动校验，必须输出 `≤400 ✅` 方可渲染。
- 建议留余量：控制在 **350–400 字**之间，避免临界风险。

## 3. 内容结构（一段话，不分点）

按以下**六要素**浓缩成一段（机制研究类与非机制类二选一使用第 4 要素）：
1. **研究背景**（约 60–80 字）：领域重要性。
2. **当前待解决的问题**（约 60–80 字）：领域现存的矛盾/瓶颈/空白。
3. **本项目发现什么 / 做了初步研究**（约 60–80 字）：申请人前期工作、调研发现或初步结果（须与"研究基础"一致，零基础用户可写前期调研与论证）。
4. **科学假说（机制研究类使用）/ 项目的目的（非机制类使用）**（约 40–60 字）：机制研究类给出科学假说；方法/工具/应用类写本项目拟达成的目的。
5. **怎么实现这项研究**（约 80–100 字）：核心研究内容与关键技术路线要点。
6. **研究的意义**（约 40–60 字）：科学/应用价值。

**红线：摘要不写预期成果**。禁止出现"预期形成/拟产出/发表论文 X 篇、专利/软著 X 项、培养人才 X 名、建成 X 套系统"等成果性表述——这些属于"主要技术经济指标"章节内容，写入摘要会被评审视为凑字数。

## 4. 一致性要求

- 摘要中的**题目、关键词、核心科学问题、主要创新点**必须与正文严格一致，不得出现正文没有的新概念。
- 摘要中**不出现参考文献引用**（本技能"摘要零引用"红线，与 `standards/citation-formats.md` 一致）。
- 语言精炼、学术化，避免口语与空话。
- 行文遵循资深科研工作者笔法，规避"AI 腔"套话与空泛开头（如"随着……的快速发展""近年来……日益受到广泛关注""值得注意的是"），开门见山陈述领域背景与核心矛盾（见 `writing-quality.md` §6）；不使用"本节/本文"等自指表述。
