# 标准 2：研究内容、研究目标，以及拟解决的关键科学问题

本块是评审"项目是否清晰、可行、重点突出"的关键，须**重点阐述**。严格按三个二级标题组织，每条下最多一级编号（1）（2）（3）。

## 2.1 项目的研究内容（### 2.1 研究内容）

- 用 `##### （1）` `##### （2）` `##### （3）` 组织，**最多到（1）（2）（3）这一级**，不要再嵌套。
- 每条（1）（2）（3）对应一个研究层面或子方向，与立项依据凝练的科学问题**一一呼应**。
  - 生命科学/医学：常按 分子 → 细胞 → 动物 → 临床/生信 分层。
  - AI/生信/工程：常按 数据/算法 → 模型/系统 → 验证/应用 分层。
- 每条开头用一句话点明"要做什么 + 为什么属于核心内容"，再展开 2–4 句具体设想。
- 体量须与经费/年限匹配（见 `writing-quality.md` §经费-年限-体量矩阵）。

## 2.2 研究目标（### 2.2 研究目标）

- 用 `##### （1）` `##### （2）` 列出 **2–4 条可考核目标**。
- 每条一句话，明确"通过什么手段，达到什么可验证结果"。避免空泛（如"揭示机制"应写为"明确 X 通过 Y 调控 Z 的分子机制"）。

## 2.3 拟解决的关键科学问题（### 2.3 拟解决的关键科学问题）

- 用 `##### （1）` `##### （2）` 凝练 **2 个左右**关键科学问题。
- 每条用"论证/阐明/揭示 ……"句式，点明"本项目必须攻克的、决定成败的核心难点"，并简要说明为何关键。
- 关键科学问题应高于具体实验，是"科学层面"的未知，而非技术操作。

## 质量要求

- 三块之间逻辑闭环：立项依据提出问题 → 2.1 内容回应问题 → 2.2 目标可考核 → 2.3 关键问题点出难点。
- 不出现未在前文论证过的全新概念；术语一致。
- （1）（2）（3）层级统一、编号连续。
