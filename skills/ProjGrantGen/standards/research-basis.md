# 标准 6：研究基础与工作条件

位于"三、报告正文"末尾。分两块，标题文字与提纲一致。

## 1. 研究基础（### 1. 研究基础）

- **若用户提供**已发表文献或预实验：逐条陈述，格式"前期工作表明/已发表研究表明 + 具体发现 + （已发表：文献[ N ]；预实验：标注【预实验】）"。
  - 将用户基础与立项依据论证**打通**，证明"团队已具备开展本项目的能力与线索"。
  - 已发表工作列出对应参考文献编号；未发表预实验明确标注，不冒充已发表。
- **若用户未提供**：写通用段（团队方向积累、相关平台经验），并标注 `[申请人需补充具体研究基础]`，**绝不虚构数据/论文**。**不得只写干瘪一句**——至少要覆盖以下三方面实质内容（按"零基础用户"通用模板，全部用可支撑的通用表述，不虚构业绩）：
  1. **技术调研与知识积累**：项目组已完成对项目所涉核心技术（如大语言模型智能体/某分析工具链）的系统调研，掌握基本用法与参数体系，建立了对"问题→方法→执行"技术路线的完整认识。
  2. **方法学论证与路线设计**：围绕本项目技术路线完成前期论证，明确各模块功能边界与数据契约，设计总体架构与评测框架，论证了在既定算力与经费条件下实现的可行性。
  3. **教学与示范条件**（面向高校/教学单位项目）：申请人长期从事相关方向教学，具备课程设计与实操指导经验，可为应用场景测试提供真实用户样本与评测反馈渠道，也可为成果向实训转化提供支撑。

## 2. 工作条件（### 2. 工作条件）

- **一段话**说明已具备的支撑条件：
  - 实验仪器/设备（如 测序仪、共聚焦显微镜、计算服务器配置）。
  - 算力/数据平台（GPU 服务器、已有数据库、合作医院/队列）。
  - 依托单位平台、伦理/生物安全资质、合作单位。
- 说明**尚缺少的条件和拟解决的途径**（如"缺乏 XXX，拟通过合作单位/开放平台/购置解决"）。
- 与 3.2 可行性分析、经费预算的"设备费/业务费"保持一致。
