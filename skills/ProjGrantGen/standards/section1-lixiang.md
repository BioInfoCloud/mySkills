# 标准 1：项目的立项依据（撰写规范）

立项依据是整份标书的"灵魂"，决定评委对科学价值的第一印象。本块**必须文献支撑、述评结合**，并使用本技能自带的检索/分析/引用体系（见 `standards/citation-rules.md` 与 `guides/literature-integration.md`，零外部依赖）。

## 1. 严禁"按框架小标题"逐条罗列（6.1）

**不要**写成：
> 一、研究意义 …… 二、国内外研究现状 …… 三、发展动态分析 ……

那是提纲提示语，**不是你的写作结构**。你写的是连贯的"论证性综述"，用自己凝练的论点式小标题组织。

## 2. 撰写前置流程（6.2）

1. **凝练关键科学问题**：基于题目+主题，先想清楚"本项目到底要解决哪一个/几个科学问题"。这是贯穿全文的主线。
2. **并入用户研究基础**：若用户提供了预实验或已发表文献，将其作为"已知证据"与文献一同分析，看作立论的一部分（未发表结果用"本项目前期发现/预实验表明"标注）。
3. **检索文献（越丰富越好）**：运行本技能 `scripts/literature_search.py`（或 agent 用 WebSearch 经 `--from-json` 规范化，见 `guides/literature-search.md`），优先**近 5 年、高影响因子/权威期刊**文献；文献越丰富，越利于后续推理科学问题。
4. **规划框架**（见下）。

## 3. 框架结构（强制）

- **首段：综述性总纲**（一段，不编号）。概述领域背景、当前进展、存在的核心矛盾/空白，自然引出本项目的必要性。
- **1.1 – 1.N 论点式小标题**（3–4 条，升序编号）。每条是**概括性的论点标题**，而非方法分类。示例风格：
  - `1.1 <领域核心机制>是<疾病/现象>的关键驱动因素，靶向<核心机制>是<疾病/现象>治疗的一种新策略`（占位示例，实际用本项目主题词，不得照抄）
  - `1.2 <分子通路/系统>参与调控<核心机制>，为开发针对<疾病/现象>的干预策略提供了重要研究方向`（占位示例）
  - `1.3 [若有本项目未发表基础] <关键分子>在<疾病/现象>中发挥重要作用，本项目前期发现<下调/激活><关键分子>促进了<表型>并与<核心机制>相关`（占位示例）
- **1.N 收束性论点式小标题（撰写者自拟，按领域自适应撰写）**：
  - **不新增模板没有的提纲标题**：模板对"1.项目的立项依据"只给出内容要求（研究意义、国内外研究现状及发展动态分析等），`1.1–1.N` 均为撰写者自拟的论点式**内容**小标题；填充/精简模式下模板标题原样保留，本节小标题仅作正文内部层级。
  - **禁止**以 `研究策略：` 或 `研究意义：` 加粗开头分别写一段——那是框架提示语的写法，不是论证性综述。本小节用**连续论述段落**组织，与前面背景自然连贯。
  - **生物医药/分子机制类项目**：基于前面背景介绍 → **提出科学假说**（一句话机制假设）→ 针对该假说**概括性撰写如何验证**（关键技术路线要点，不展开细节）→ 最后写**假说验证后的科学意义**。
  - **AI／生物信息领域工具开发、数据库构建类项目**（以及工程、方法学、应用类）：不提出科学假说，正文**不出现"科学假说"字样，也不自我声明"不设科学假说"**，直接基于前文背景写**开发此类工具的必要性**（现有工具/方法的空白或瓶颈）→ 写**工具开发对科学研究的重大意义** → **概括性描述如何实现该工具的开发**（技术路线要点）。
- **1.(N+1) 主要参考文献**：Vancouver 顺序编码（见 citation-rules）。

## 4. 质量红线

- **述评结合**：每段既呈现证据（引用）又给批判性评价/对比，禁止"论文流水账"式罗列。
- **每段落 ≥ 1 条引用**；近 5 年文献占比 ≥ 50%；总数 30–60 篇（依篇幅）。
- **术语缩略词规范**：自拟/专业性缩略词首次出现标注英文全称与缩写，格式 `中文（English full name, 缩写）`（如"肿瘤相关巨噬细胞（tumor-associated macrophage, TAM）"）；同一术语后续出现一律只写缩写，不重复英文全称。**例外**：学科通用缩写（DNA/RNA/PCR/AI/CT 等）首次可不注全称；基因/蛋白/化学修饰符号（TP53、mTOR、m6A 等）本身即规范符号，不重复英文全称。
- **括号使用规范**：术语后括号仅用于标注英文全称与缩写，不得塞入其他无关话题、描述或文献编号；引用 `[N]` 置于句末，严禁写进术语括号内。错误示例："肿瘤相关巨噬细胞（tumor-associated macrophage, TAM，m6A 相关基因与肺腺癌预后免疫相关[21]）作为肿瘤治疗工具与靶点已被系统评述[22]"——括号内混入无关内容且引用位置错误，应改为"肿瘤相关巨噬细胞（tumor-associated macrophage, TAM）……已被系统评述[22]"。
- **缺口聚焦（只写与主题直接相关的不足）**：现状综述中提出的"不足/空白/挑战/争议"必须直接服务于本项目要解决的科学问题，并与 2.1 研究内容、2.2 研究目标、2.3 关键科学问题构成因果关系；**不得罗列与研究主题无关的短板**，如伦理与监管框架、政策配套、社会接受度、研究人员认知不足、跨学科协作困难等（除非项目主题本身就是该方向）。反例与说明见 `writing-quality.md` §6.4。
- **禁自指式元叙述**：不得出现"本节围绕/本节主要介绍/本节将/下面将/接下来/如前所述/综上所述"等对文稿自身结构的指称；确需点明项目范围用"本项目围绕……"或直接省略。行文须符合资深科研工作者笔法，规避"AI 腔"套话（见 `writing-quality.md` §6）。
- 不夸大、不贬低前人；客观指出"尚未解决/存在争议/缺乏证据"。
- 所有事实性断言须可溯源；不虚构数据或结论。

## 5. 自检清单

- [ ] 未出现"研究意义/国内外现状"等框架小标题作为写作结构
- [ ] 首段为综述总纲；小标题 3–4 条且为论点式、1.1→1.N 升序
- [ ] 1.N 小节按领域自适应撰写：机制类＝提出科学假说→概括验证方案→验证后科学意义；工具开发/数据库构建类＝开发必要性→对科研的重大意义→如何实现工具开发（本类不写科学假说，正文不得出现"不设科学假说""无假说"等自我声明）
- [ ] 1.N 小节未使用 `研究策略：`/`研究意义：` 加粗开头分段写法（正文一律不使用「」字符；引用/强调用中文弯引号“”）
- [ ] 若有用户基础，已在对应小节明确标注"本项目前期发现/预实验表明"
- [ ] 每段落有引用；近 5 年 ≥50%；无占位区间 `[21-157]`；引用已重编号
- [ ] 参考文献每条被引 ≥1 次，每条正文引用有对应条目
- [ ] 无自指式元叙述（"本节围绕/本节将/如前所述/综上所述"）
- [ ] 所述"不足/空白"均与研究主题直接相关，未罗列伦理/监管/政策/认知等无关短板
- [ ] 行文无"AI 腔"套话（见 `writing-quality.md` §6）
