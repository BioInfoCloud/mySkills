# 立项依据深度分析框架（强制，介于筛选与起草之间）

本框架将"原始文献列表"转化为"可驱动的批判性分析素材"，是写出 Nature Reviews 级
立项依据（述评结合、而非论文流水账）的基础。脚本 `scripts/analysis_skeleton.py`
会生成 `analysis_output.md` 骨架（含全部 FILL 占位），本指南定义每个环节的填写规范。

## 0. 单一输出文件（重要）

**所有分析产物只写入一个文件：`<project_slug>/analysis_output.md`**。不要为各聚类拆文件。
该文件是起草立项依据的唯一素材库；拆分只会增加起草难度。

## 1. 预印本审计（内部质控，不进正文）

- **所有领域（含 CS/AI）一律禁止引用预印本**：arXiv / bioRxiv / medRxiv / Research Square /
  SSRN / 其他 preprint server 条目均不进入参考文献。
- 筛选阶段（`scoring-system.md` §4 自动排除）已排除全部预印本 → 在 `analysis_output.md`
  记 `Preprint Audit: N/A（全部预印本已在筛选阶段排除）`。
- 若某篇论文仅有预印本、无同行评议正式版，则**不选该篇**；不可用预印本顶替正式版。
- 若发现引用了预印本，用 Crossref/OpenAlex 逐篇核对其**正式出版版本**并入列。
- **审计结果绝不在立项依据正文中出现**（"预印本审计"等词不得写进标书）。

## 2. 逐篇结构化提取（9 字段，全部文献都要做）

| 字段 | 提取内容 | 示例 |
|------|----------|------|
| 研究对象 | 生物实体/系统/模型/数据集 | <细胞系/队列/数据集名>（**占位示意**） |
| 核心方法 | 关键实验/计算方法 | <技术名>；<组学方法>+<分析工具>；<模型类型> |
| 实验方案 | 设计：样本量/分组/对照/周期 | <基因型/干预>→<细胞/动物模型>→<处理>（**占位示意**） |
| 关键结果 | **带数字的定量发现** | <分子> KD→<表型> ↑<倍数>(p<...>)；<指标> <数值>±<SD>（**占位示意**） |
| 创新点 | 相对既往的新颖处 | <与既往的差异点>（**占位示意**） |
| 局限性 | 承认或可识别的局限 | <仅体外/无体内验证/样本量不足等>（**占位示意**） |
| 适用边界 | 该证据*证明*与*未证明* | <证相关非因果/仅某模型下验证>（**占位示意**） |
| 作者结论 | 作者自述意义 | <作者对意义的表述>（**占位示意**） |
| 来源质量 | 期刊层级/同行评议状态（预印本一律不选） | Tier1(<顶刊>)、Tier2(<优质刊>)、Tier3(<专科刊>)；[预印本 → 排除] |

## 3. 批量聚类（五个独立维度，同一篇可多处出现）

- **A 研究方法**：分子/结构/组学/临床/计算/生化；CS：监督/无监督/强化/生成。
- **B 研究视角**：机制/功能/疾病/方法学/理论。
- **C 结论方向**：正向支持/负向矛盾/中性条件/探索描述。
- **D 证据等级**：Tier1（顶刊大样本多中心）/Tier2（优质专科刊）/Tier3（稳健但局限）。
- **E 应用场景**：体外/体内动物/临床人/计算模拟/工业。

## 4. 横向对比分析（强制，每个聚类一张表）

| 维度 | 文献A[Ref] | 文献B[Ref] | 文献C[Ref] | 分析 |
|------|-----------|-----------|-----------|------|
| 研究体系 | | | | 哪个更贴合本项目 thesis？ |
| 关键方法 | | | | 分辨率/范围/通用性差异？ |
| 关键结果(带数) | | | | 结果是否一致？量级差？ |
| 证据等级 | | | | Tier1>Tier2>Tier3 |
| 统计效力 | | | | 样本量充足？多重校正？ |
| 关键优势 | | | | 独特贡献？ |
| 关键局限 | | | | 无法告诉我们什么？ |

识别：共识（多独立组复现→"consensus"论断）、矛盾（分析成因：模型/试剂/统计/批次）、
方法优劣、条件依赖、证据梯度（RCT/荟萃>队列>单实验>多中心重复性研究，预印本不参与证据梯度）。每表配 2–5 句小结 + 置信度（高/中/低）。

## 5. 集体局限性

- 共性：领域系统性偏差（如只用一种细胞系）、关键试剂/基准是否验证、统计标准是否充分。
- 个例：特定研究弱点；撤稿/被严重质疑标 `[CAUTION: retracted/superseded]`。
- 领域瓶颈：限制进展的最大因素；最该补的实验/数据。

## 6. 研究空白（GAP，须可溯源/具体/可操作/有优先级）

| 类型 | 定义 | 示例 |
|------|------|------|
| 未探索 | 无任何研究 | <分子/机制>在<组织/场景>中功能完全未知（**占位示意**） |
| 欠探索 | 仅 1–3 篇 | 仅研究了皮层一个脑区 |
| 争议 | 结果冲突无定论 | <分子>抗氧化 vs <另一功能>，证据冲突（**占位示意**） |
| 方法薄弱 | 关键缺陷限制解读 | 全体外，缺体内验证 |
| 无转化 | 模型强但缺人验证 | <分子/机制>轴动物强、人数据缺（**占位示意**） |
| 证据质量 | 低层级主导 | 多为小样本单中心无重复 |

每条须：有依据（可追到具体文献）、具体（非"需更多研究"）、可操作（具体实验/数据）、有优先级。

## 7. 时效与质量评估

- 年龄结构：按年分布，识别缺失年份。
- 被推翻发现：新研究反驳的旧结论，标出。
- 过时方法：旧技术未注明局限。
- 前沿比：近 2 年占比；活跃领域 <15% 则定向补检索。
- 质量结构：Tier1/2/3 占比；>30% 为 Tier3 则扩检或警示。

撤稿/更正/被严重质疑者标 `[CAUTION: retracted/superseded/questioned]`。

## 8. 客观性

- 分析中用 `[EVIDENCE]` 标事实、`[ANALYSIS]` 标点评，二者分开。
- **最终写入标书正文时删除所有 `[EVIDENCE]/[ANALYSIS]` 等内部标记**，呈自然学术散文。
- 不编造数字/p 值/fold-change/样本量/基准分；不把论断安给未含此内容的文献。
- 关键大效应/范式性论断，至少跨一库核验（PubMed+Crossref 或 OpenAlex+Semantic Scholar）。

## 9. analysis_output.md 结构顺序

1. Preprint Audit → 2. 逐篇 9 字段提取 → 3. 五维聚类 → 4. 横向对比表 →
5. 集体局限性 → 6. 研究空白 → 7. 时效与质量 → 8. 撰写建议（含框架草案）。
