# 默认模板结构映射（编码自 医学标书模板.doc）

当用户未提供模板时，按本文件结构重建输出。本文件是**贵州省教育厅科研项目**申请书模板的完整骨架，仅含结构，不含任何示例内容。所有标题文字（含括号提示）必须与下方完全一致，不得删改。

## 顶层顺序（严格按此）

1. 一、项目基本信息
2. 项目摘要（限 400 字）+ 关键词
3. 二、主要参与者（注：主要参与者不包括项目申请人）
4. 三、报告正文
5. 四、经费预算表（单位：万元）
6. 签字和盖章页（申请人承诺书 / 单位承诺书，诚信承诺正文照模板原样输出）
7. 附件清单

---

## 一、项目基本信息（表格化填空）

| 字段组 | 字段 |
|--------|------|
| 项目基本信息 | 项目名称、项目类别（重大项目 / 重点项目 / 一般项目 / 青年项目，勾选其一）、研究起止年月（年 月 - 年 月）、申请经费（万元） |
| 项目负责人信息 | 姓名、性别、出生年月、民族、学历学位、职称、工作单位、手机、所属学科、主要研究领域 |
| 合作单位 | 序号、单位名称、组织机构代码、联系人、手机（可多行 01/02/03） |

## 项目摘要 + 关键词

- 标题原文：`项目摘要` / `项目主要研究内容及主要经济技术指标（限400字）` / `关键词`
- **摘要 ≤ 400 字，标点与字母均计 1 字**（硬约束，见 `standards/abstract-rules.md`）。

## 二、主要参与者（表格）

列：序号、姓名、出生年月、性别、职称、学历学位、工作单位、项目分工、电话。
底部统计：项目组总人数、高级职称、中级、初级、博士后、博士生、硕士生、其他人员。

## 三、报告正文（核心，见 `references/nsfc-framework.md`）

模板 T3 表共 3 行、每行 1 个单元格；**每个小节标题是单元格内的独立段落，标题之间是一串模板空行**。填充必须**按小节标题定位插入**（`generate_docx.py` 的 `_insert_md_after_heading`：先删模板空行，再把内容插到对应标题之后），绝不能追加到单元格末尾——否则正文会与标题错位（立项依据内容落到"2."标题之后、方案/创新/指标全部落到"5."标题之后）。

结构（→ 锚点标题 → 插入内容块）：
- （一）立项依据与研究内容（建议 8000 字以下）〔模板块标题，不写内容〕
- r0 单元格：
  - → `1.项目的立项依据`：sec1（研究意义、国内外研究现状及发展动态分析、领域自适应小节【1.N：机制类=科学假说→概括验证→验证后科学意义；工具开发/数据库构建类=开发必要性→对科研意义→实现方式（本类不写科学假说）；禁止用"研究策略：""研究意义："加粗分段开头】、附主要参考文献目录）
  - → `2.项目的研究内容`：sec2（研究内容、研究目标、拟解决的关键科学问题、主要技术难点及解决思路；此部分需重点阐述）
- r1 单元格：
  - → `3.拟采取的研究方案及可行性分析`：sec3（研究方法、技术路线、实验手段、关键技术等说明）
  - → `4.本项目的特色与创新之处`：sec4（特色与创新点）
  - → `5.主要技术经济指标及社会效益说明`：indicators（可考核指标 + 社会效益；**预期成果写在这里，不写进摘要**）
- r2 单元格：
  - 研究基础与工作条件〔模板块标题，不写内容〕
  - → `1.研究基础`：base1（与本项目相关的研究工作积累和已取得的研究工作成绩）
  - → `2.工作条件`：base2（已具备的条件、尚缺少的条件和拟解决的途径）

**字体规范**：新增内容中文用楷体（w:eastAsia），英文/数字一律用 Times New Roman（w:ascii/hAnsi/cs），由 `_style_fill_run` 统一处理。

## 四、经费预算表（单位：万元）

- 顶部：预算总经费、省级财政经费、学校配套经费、其他渠道经费。
- 科目表（列：序号、预算科目名称、总额、其中：省级财政经费）：
  1 经费支出（合计）；2 一、直接费用；3 1.设备费；4 其中：设备购置费；5 2.业务费；6 3.劳务费；7 二、间接费用；8 其中：绩效支出。
- 预算说明书（备注原文照录）：政策相符性、目标相关性、经济合理性三原则；单价≥50 万元设备详细说明，<50 万元分类说明；合作研究单位资质及资金外拨、自筹资金必要说明。
- 直接经费说明三段：设备费：／业务费：／劳务费：（按实际填写）。
- 计划进度及目标（按年度）：列 开始日期-结束日期、阶段目标。

## 签字和盖章页

照模板原样输出两段诚信承诺（申请人承诺书、单位承诺书）正文，保留"申请人签字：""依托单位公章 日期：""合作研究单位公章：日期："等占位。
