# 报告正文通用骨架（Generic 正文 Framework）

本文件定义"报告正文"的**通用章节骨架**，适用于 NSFC、省教育厅及同类中文科研项目申报书。它从标准 NSFC 正文提纲抽象而来，**不含任何具体项目内容**——只规定层级、标题文字与每块应覆盖的要点。撰写时严格套用，标题文字（含括号提示语）不得改动。

> 提纲原文提示（NSFC）："参照以下提纲撰写，要求内容翔实、清晰，层次分明，标题突出。请勿删除或改动下述提纲标题及括号中的文字。"

---

## （一）立项依据与研究内容（建议 8000 字以下）

### 1. 项目的立项依据
- **1.0 综述性总纲**（一段）：先写领域背景，再点出核心科学/应用矛盾，最后说明本项目为何重要。
- **1.1 – 1.N 论点式小标题**（3–4 条，升序）：每条是一个凝练的"论点"，而非框架小标题。例式：
  - `1.1 X 是 Y 的核心因素，靶向 X 是 Z 的新策略`
  - `1.2 A 系统参与调控 B，为开发 C 提供方向`
  - `1.3 [若有未发表基础] D 在 E 中发挥重要作用，本项目发现……`
- **1.N 收束性论点式内容小标题（撰写者自拟，按领域自适应撰写，禁止加粗分段）**：
  - **不新增模板没有的提纲标题**：模板标题（如"1.项目的立项依据（研究意义、国内外研究现状及发展动态分析…）"）原样保留；正文内部的 `1.1–1.N` 由撰写者自拟，仅作内容层级。
  - **生物医药/分子机制类**：基于前文背景，提出**科学假说**（一句话机制假设）；随后概括说明**如何验证该假说**；最后写出**假说验证后的科学意义**。
  - **AI／生物信息工具开发、数据库构建类**（及工程/方法学/应用类）：不提出科学假说，正文**不出现"科学假说"字样，也不自我声明"不设科学假说"**；基于前文背景，说明**开发此类工具的必要性**；再阐述**工具开发对科学研究的重大意义**；最后概括描述**如何实现该工具开发**。
  - **禁止**以 `研究策略：`／`研究意义：` 加粗开头分别写一段；本小节用连续论述段落与背景自然衔接。
- **1.(N+1) 主要参考文献**：Vancouver 顺序编码，近 5 年 ≥50%，30–60 篇。

### 2. 项目的研究内容、研究目标，以及拟解决的关键科学问题
- **2.1 研究内容**：按（1）（2）（3）组织（最多一级），每条对应一个子目标/层面（分子/细胞/动物/临床/算法/系统）。
- **2.2 研究目标**：按（1）（2）（3）列出可考核目标。
- **2.3 拟解决的关键科学问题**：按（1）（2）凝练 2 个左右"问题"，每条用一句话明确"要解决什么"。
- **2.4 主要技术难点及解决思路**：按（1）（2）列出 1 至 3 个技术难点，每条写"为何难"与"如何解决"（模板明确要求"主要技术难点和问题分析"；可单设 2.4，或并入 2.3、3.2 逐条说明，但正文中不得缺失该内容）。

### 3. 拟采取的研究方案及可行性分析
- **3.1 研究方案**：按"第一部分 / 第二部分 …"对接 2.1 的研究内容，每部分含技术路线（标注 `[图X-Y 技术路线图]` 占位）+ 详细实验/方法步骤（用（1）（2）…）。**常规技术不展开**（如 Western blot、Transwell 一句话带过）。
- **3.2 可行性分析**：分"理论可行 / 技术可行 / 条件可行"，明确区分**【已完成】**与**【拟开展】**。

### 4. 本项目的特色与创新之处
- 2–4 条，每条"特色/创新点 + 简要依据"，**不夸大、不空泛**。
- **创新表述 4 原则**：① 先承认已有，再指出缺口，最后说改进（不做"首次/填补空白"开场）；② 可落地可验证（对应量化效果或可执行流程，拒绝空泛"新范式/新框架"）；③ 区分"首创"与"优化/定制/集成"（领域适配、集成、方法优化本身即合格创新）；④ 创新点与可行性绑定（隐含"我们有基础能做到"）。详见 `standards/section4-innovation.md`。

### 主要技术经济指标及社会效益说明
- 列出可考核的技术/经济指标（性能、精度、成本、周期等）；社会效益结合国家/地方政策（如"健康中国 2030""新质生产力""算力基础设施"等）阐述。

### 研究基础与工作条件
- **1. 研究基础**：用户提供的已发表/预实验基础，逐条陈述；无则通用段 + `[申请人需补充]`。
- **2. 工作条件**：一段说明已具备的仪器、服务器/算力、平台、合作单位，及缺少条件与解决途径。
