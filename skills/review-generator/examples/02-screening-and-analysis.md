# 二、筛选与深析

> 样例为合成示例：为演示流程形态而构造，文献以 P1 至 P5 等匿名标识表示，不指代任何真实论文，也不含真实 DOI 或期刊名。真实运行时，文献元数据一律来自检索结果与 Crossref，禁止凭记忆生成。

| C2 | 病毒组失调与炎症性肠病 | 28 | 18 | 17 | 15 | 6 | 3 | 87 | 选入 |

## 2. 筛选后质量闸门

| 检查项 | 结果 |
|---|---|
| 主题范围 | 4 个候选子主题，收窄为 3 个核心主题 |
| 文献时效 | 选入集合中位发表年份落在近 3 年内 |
| 前沿覆盖 | 近两年文献占比 40%，高于 20% 下限 |
| 证据充分性 | 样例压缩至 5 篇；真实运行须达到 100 篇以上，不足时记录质量说明 |
| 结构比例 | 近 3 至 5 年前沿研究 60%，奠基性工作 20%，其余为背景 |
| 质量构成 | Q1 与 Q2 期刊为主，预印本已全部剔除 |
| 数据库多样性 | 命中来自 4 个数据库，满足不少于 3 个的要求 |

## 4. 九字段深析

`analysis_skeleton.py` 生成 `analysis_output.md` 骨架，随后逐篇填入九字段。以下为 P1 的完整提取与 P2 的节选。

| 字段 | P1 | P2 |
|---|---|---|
| 研究对象 | 无菌小鼠与常规饲养小鼠的肠黏膜免疫细胞 | 炎症性肠病患者队列，交叉对照 |
| 核心方法 | 噬菌体定植结合单细胞转录组 | 宏基因组测序与临床指标关联 |
| 实验方案 | 三组对照，每组 8 只，定植后 14 天取样 | 两组比较，样本量 487，随访 12 个月 |
| 关键结果 | 噬菌体定植后调节性 T 细胞比例上升 3.2 倍，p 小于 0.01 | 病毒组多样性指数与疾病活动度呈负相关，r 为负 0.42 |
| 创新点 | 首次在体内证明噬菌体直接塑造黏膜免疫格局 | 首次在大人群队列中量化病毒组失调的程度 |
| 局限性 | 仅小鼠模型，无人体验证，样本量小 | 相关性设计，无法判定因果方向 |
| 适用边界 | 支持机制可能性，不支持因果结论 | 支持关联结论，不支持干预效应 |
| 作者结论 | 噬菌体是黏膜免疫稳态的调节因子 | 病毒组失调可作为疾病活动度的伴随标志 |
| 来源质量 | 第二档，Q1 专科期刊，同行评议 | 第一档，顶级期刊，同行评议 |

## 5. 五维聚类

按方法、视角、结论方向、证据层级、应用场景五个维度对选入文献聚类，单篇可同时落入多个簇。

| 维度 | 分布 |
|---|---|
| A 研究方法 | 分子生物学 P1、P4；组学 P2、P5；临床转化 P3 |
| B 研究视角 | 机制 P1、P4；疾病 P2、P3；方法学 P5 |
| C 结论方向 | 正面 P1、P4；条件性 P3；探索性 P5；矛盾 P2 与 P4 部分相左 |
| D 证据层级 | 第一档 P2；第二档 P1、P3；第三档 P4、P5 |
| E 应用场景 | 体内动物 P1、P4；临床人群 P2、P3；计算模拟 P5 |

## 6. 横向比较

每个主题簇构建一张比较表，沿共同维度逐篇对照，这是深析的核心产物。

| 维度 | P1 | P2 | P4 | 分析 |
|---|---|---|---|---|
| 研究体系 | 小鼠黏膜 | 患者队列 | 小鼠细胞系 | P2 的人群相关性最高，P1 的机制分辨率最高 |
| 核心方法 | 单细胞转录组 | 宏基因组测序 | 通路敲除 | 分辨率与覆盖范围不同，结论方向因此分化 |
| 关键结果 | 调节性 T 细胞上升 3.2 倍 | 多样性指数与活动度负相关 | 先天免疫通路激活减弱 | 三项结果指向同一方向，强度不同 |
| 适用边界 | 机制可能性 | 人群关联 | 通路必要性 | 证据类型互补，不能相互替代 |

## 7. 主题分组

由聚类结果提炼 3 个核心主题，作为正文的二级标题来源。

| 主题 | 支撑文献 | 该主题要回答的问题 |
|---|---|---|
| 噬菌体对黏膜免疫稳态的直接调控 | P1、P4 | 噬菌体是否直接塑造免疫格局，证据强度如何 |
| 病毒组失调与疾病的关联形态 | P2、P3 | 关联是否稳健，能否支持因果推断 |
| 病毒组研究的方法学约束 | P5、P4 | 现有方法的分辨率边界如何限制结论 |

深析后运行质量闸门，确认每个主题均有足够文献支撑，再进入起草。
