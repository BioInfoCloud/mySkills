# 端到端样例

本目录给出一个完整的运行样例，用于说明从用户输入到最终产出物的全过程，并演示各步骤的中间产物形态。

## 样例说明

样例为合成示例。为演示流程形态而构造，其中文献以 P1 至 P5 等匿名标识表示，不指代任何真实论文，也不含真实 DOI 或期刊名。真实运行时，文献元数据一律来自检索结果与 Crossref，禁止凭记忆生成。

## 阅读路径

| 文件 | 内容 |
|---|---|
| `01-input-and-search.md` | 用户输入、领域与综述类型判定、检索查询组、各库命中统计 |
| `02-screening-and-analysis.md` | 六维评分与筛选、选入集合、九字段深析、五维聚类与主题分组 |
| `03-drafting-and-translation.md` | 占位骨架、替换后的英文段落、反例与改写对照、中文段落 |
| `04-deliverables-and-validation.md` | 产出物清单、校验输出、续跑与错误报告示例 |

若只想了解最终产出长什么样，直接读 `04-deliverables-and-validation.md`；若关心质量是如何被控制的，按顺序读。

## 样例主题

用户输入：写一篇肠道病毒组与宿主免疫相互作用的研究进展综述。

判定结果：领域 `biomedical`，综述类型 Comprehensive/Narrative，模板 `templates/template-narrative.md`，目标文献量 100 至 200 篇，英文篇幅 8,000 至 12,000 词。

样例为控制篇幅，将检索与筛选规模压缩到 8 篇候选、5 篇选入，用于展示形态；真实运行时文献量按模板契约执行。
